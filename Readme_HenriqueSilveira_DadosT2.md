## Estrutura do Projeto

O projeto está organizado da seguinte forma:
* `data/`: Contém a base de dados utilizada na análise.
* `notebook/`: Contém o arquivo onde a análise de dados foi realizada.
* `utils/`: Módulo interno com o arquivo `__init__.py` e a biblioteca de funções customizadas que auxiliam no processo de análise.
* `README_HenriqueSilveira_DadosT2.md`: Instruções de execução do projeto (este arquivo).

---
**Requisitos para execução**

Certifique-se de ter o Python instalado em sua máquina ou utilize o ambiente em nuvem do Google Colab.

* Python 3.x

## Como Executar 

Você pode rodar este projeto de duas formas (localmente ou na nuvem). Escolha a opção de sua preferência:

### Opção 1: No Google Colab 
1. Acesse o [Google Colab](https://colab.research.google.com/).
2. Faça o upload do arquivo do projeto e execute

### Opção 2: Localmente no VS Code ou Terminal
1. Abra a pasta do projeto no **VS Code**.
2. Abra o terminal integrado e instale as dependências necessárias 
3. Acesse a pasta `notebook/` e abra o arquivo do notebook.
4. Clique no botão **"Executar tudo"** (Run All) no topo do notebook.
